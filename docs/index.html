日本語で直感的に書けるプログラミング言語

JAPlus (JA+) は、かぎ括弧や角括弧を使ったシンプルかつ強力な日本語プログラミング言語です。

最新版をダウンロード GitHub (main)

JA+ の特徴

完全な日本語ベース

「変数」や「出力」といった自然な日本語でプログラムを構築できます。

多彩な機能

HTTP通信や外部プロセスの起動、条件分岐、ループ処理などをスマートに実行可能。

シンプル・軽量

かぎ括弧や角括弧を使った明快なルールで、直感的に記述できます。

基本文法

変数宣言

かぎ括弧で変数を指定します。

「変数名」を ［値］ にする

出力

テキストや数値をコンソールに出力します。

［テキスト］ を出力する

計算

コロンで囲んで計算処理を行います。

「変数」を: 50 + 20 :にする

条件分岐

条件に一致する場合に処理を実行します。

「変数」が ［true］ なら、［処理］ を出力する
